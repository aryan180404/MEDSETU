An ECG, from electrode to browser.

MEDSETU reads the heart’s electrical signal with an Arduino ECG, cleans it, streams it to the web and draws it live, with an AI-written reading on request.

Open the live dashboard See how it works

Live when the device is running. Recorded demo patients are always available.

Plate II

From skin to screen, in six steps.

Every part of the pipeline was built for this project: the hardware, the filtering, the streaming and the dashboard.

  1. 01

    Electrodes

    Skin electrodes on the right and left arm pick up the heart’s tiny voltage (Lead I).

  2. 02

    Arduino ECG

    The prototype board amplifies the signal and samples it with its ADC.

  3. 03

    Python filter

    A script cleans the noise and streams the filtered readings to the web.

  4. 04

    Google Sheet

    Each reading lands as a timestamped row the dashboard can fetch.

  5. 05

    Live dashboard

    The browser checks for new rows every 2 seconds and redraws the trace.

  6. 06

    AI report

    On request, Gemini writes a plain-language reading, downloadable as a PDF.

  • Not a medical device

    A working student prototype. It explains a signal; it doesn’t diagnose one.

  • Live only when it’s on

    “No active stream” just means the ECG isn’t running right now.

  • Synthetic patients

    The 50 records on the dashboard are generated demo data, not real people.
